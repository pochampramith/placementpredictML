About SmartPlacement

SmartPlacement is a Machine Learning powered web application that predicts whether a student will be Placed or Not Placed, and estimates their expected salary (in LPA) based on academic and skill parameters such as CGPA, internships, projects, backlogs, aptitude score, soft skills, communication skills, and extracurricular activities.

  • Backend: Flask (Python)
  • ML Models: Random Forest Classifier + Regressor (scikit-learn)
  • Frontend: HTML5, CSS3, Bootstrap 5, JavaScript, Chart.js
